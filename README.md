# UrbanGol 🏆

UrbanGol is a modern football store built with Next.js 16, Tailwind CSS and Clerk. Features include product filtering, shopping cart and dynamic team and league pages.

## Tech Stack

- **Framework** — Next.js 16 (App Router + Turbopack)
- **Styling** — Tailwind CSS v4
- **Authentication** — Clerk
- **Language** — TypeScript

## Features

- 🛒 Shopping cart with persistent state
- 🔍 Product search and filtering
- 👕 Dynamic team and league pages
- 🏆 Era-based product browsing (90s, 00s, 10s)
- 📱 Fully responsive with mobile navigation
- 🔐 Authentication with Clerk
- ⚡ Fast image optimization with Next.js Image
